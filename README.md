# Antixor Hospital – Landing Page

Next.js 15 (App Router) · React · Tailwind CSS 3 · Lucide React

```bash
npm install
npm run dev
```

- Section components live in `components/`; shared copy and image URLs are in `lib/data.js`.
- Images are Unsplash placeholders: replace them with your own files in `/public` for production.
- The booking form calls `handleSubmit` in `components/AppointmentForm.jsx`; connect it to your API.
